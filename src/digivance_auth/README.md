# digivance_auth
This folder contains our typescript monorepository.  This repository contains various pnpm packages such as a reusable react component library, an admin portal ui, and an api client package.

# app 
The app folder is where our actual admin portal UI source is. This is a React typescript application using PNPM and Vite. If you are looking to modify the site ui this is where you want to go.

# packages
The packages folder contains shared npm packages related to, and that integrate with our API (@digivance-auth/apiclient for example). If you are looking for the api client for calling Digivance.Auth.Api endpoints this is where you want to go.
