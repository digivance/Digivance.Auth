# How to contribute
We are still getting started but are welcome to assistance.  Please get in contact with us:

__Github Discussions__ https://github.com/digivance/Digivance.Auth/discussions  
__Discord__ https://discord.gg/xbn8CxdhhK  
__Email__ support@digivance.com  

We are hoping to find additional contributors who are interested in our mission to provide a simple yet robust platform of microservice tools.  

## How do we work
We leverage GitHub issues as a task board.  Our habit is to create a branch based off dev, named task/# where # is the number of the git hub issue.  When ready, push and create PR. We are currently working on getting some more base level code committed and working on expanding our planning via the github issues, please stay tuned.
