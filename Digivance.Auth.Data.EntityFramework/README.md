# Digivance.Auth.Data.EntityFramework
This folder contains entity framework implementations of our Digivance.Auth.Data services along with supporting services and configuration.

[Contexts](./Contexts) is where we define our entity framework data context objects.

[Entities](./Entities) is where we define our entity framework entities and their type configurations.

[Services](./Services) is where we define our actual Digivance.Auth.Data.Service implementations.
